
# Student Attendance Management System

## Project Overview
The Student Attendance Management System is a web-based project designed to help manage student information and attendance records through a simple interface.

## Features
- Dashboard with student and attendance summaries
- Student management page
- Attendance page
- Attendance reports page
- Responsive user interface
- Navigation between pages

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project Structure
```text
student-attendance-management-system/
├── index.html
├── students.html
├── attendance.html
├── reports.html
├── attendance.js
├── style.css
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Navigate through Dashboard, Students, Attendance, and Reports.
